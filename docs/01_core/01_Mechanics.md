# Основные правила Маготеха (Magitech Core Rules)

В этом мире магия не берется из воздуха. Она заключена в **Эфирных Камнях**, которые служат источником энергии и "программным кодом" для оружия.

## 1. Основы стрельбы
Вместо Силы или Ловкости для атаки оружием ближнего боя, все персонажи используют **Ловкость (Dexterity)** для стрельбы.

*   **Бросок атаки:** 1d20 + Бонус мастерства (если владеете) + Модификатор Ловкости.
*   **Урон:** Зависит от оружия + Модификатор Ловкости (или Интеллекта для некоторых классов).

## 2. Система Эфирных Камней (Ether Stones)
Оружие само по себе — это просто проводник. В него вставляются **Магазины-Камни**.

### Структура Камня
Каждый камень имеет две характеристики:
1.  **Заряд (Charge):** Количество выстрелов до перезарядки (аналог боезапаса).
2.  **Емкость (Capacity):** Сколько "весит" магия, которую можно в него записать. Обычно от 1 до 5 слотов.

### Компоненты (Components)
Персонажи не просто покупают патроны. Во время отдыха они "программируют" свои камни, вкладывая в них **Компоненты**.
*   Каждый компонент занимает определенное количество **Емкости**.
*   Сумма емкости компонентов не может превышать Емкость камня.

> **Пример:**
> У вас есть *Рубиновый Камень* (Емкость 3).
> Вы вставляете в него:
> *   [Пиро-элемент](../03_stones_and_components/01_Spell_Components.md#пиро-элемент) (Занимает 1 слот) — пули наносят урон огнем.
> *   [Взрывной капсюль](../03_stones_and_components/01_Spell_Components.md#взрывной-капсюль) (Занимает 2 слота) — пули взрываются при попадании.
> **Итог:** Вы стреляете разрывными огненными пулями.

## 3. Перегрев (Overheat)
Магическое оружие нестабильно.
*   Если при броске атаки выпадает **натуральная 1**, оружие **Заклинивает**. Нужно потратить Бонусное действие, чтобы его починить.
*   Если выпадает **натуральная 20**, происходит **Магический Выброс**: эффект компонента удваивается, но оружие нагревается (следующий выстрел с помехой).

## 4. Перезарядка
*   **Смена камня:** Бонусное действие (или Действие для тяжелого оружия).
*   **Зарядка камня:** Требует короткого отдыха и концентрации маны.
